# Testing view

The Testing view (⚗ in the activity bar) lists and runs tests from five frameworks:

| Framework | Found in | Runs with | Results from |
|---|---|---|---|
| JUnit (Gradle) | `src/test/java`, `src/test/kotlin` | `gradlew test --tests …` | Gradle's JUnit XML |
| pytest | `test_*.py`, `*_test.py` | `python -m pytest` | pytest's JUnit XML report |
| Rust | `#[test]` functions in a Cargo project | `cargo test` | `cargo test` output |
| Vitest | `*.test.*` / `*.spec.*` / `__tests__/`, when `package.json` lists vitest | `node node_modules/vitest/vitest.mjs run` | Vitest's JUnit report |
| Jest | same files, when `package.json` lists jest | `node node_modules/jest/bin/jest.js` | Jest's `--json` report |

- **Listing tests never runs your code.** NOVA reads the source files. Tests generated by pytest fixtures/plugins or Rust macros aren't listed, but they still run and appear in the counts.
- **Running tests needs a trusted folder,** because tests execute project code (build scripts, conftest.py, proc macros).
- **Run All** runs every framework found in the folder, one after another. **Rerun Failed** reruns exactly the failed tests. ▶ on a file, class, module or single test runs just that.
- **Python:** NOVA uses the folder's `.venv`, `venv` or `env` virtualenv if there is one, otherwise `python3` (`python` on Windows). The first line of the output says which. Install pytest into that interpreter (`python -m pip install pytest`).
- **Rust:** `cargo test` doesn't report how long each test took, so no time is shown for Rust tests. Passing tests' printed output is shown because NOVA runs with `--show-output`.
- **JavaScript/TypeScript:** install your project's dependencies first (`npm install`, `pnpm install`…). NOVA runs the Vitest or Jest from your `node_modules` with the `node` on your PATH. Tests whose names are computed (template strings with `${…}`, `.each` tables) aren't listed, but they still run and are counted.
- **Debugging** a single test (🐞) is available for JUnit and pytest.
